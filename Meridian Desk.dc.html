Connect Upstox live data

The desk is running on realistic demo candles. The detection & strategy logic is fully live — only the feed is sample data. To stream real market data, wire your Upstox API into the data layer:

  1. Complete the Upstox OAuth flow on your backend to obtain an access token (it cannot live safely in the browser).
  2. Expose window.UPSTOX_ACCESS_TOKEN via your proxy.
  3. The app calls /v2/historical-candle/intraday/{key}/{interval} per instrument.
  4. Instrument keys are already mapped (e.g. NSE_INDEX|Nifty 50).
This build ships with a Next.js backend that handles OAuth and proxies Upstox server-side, so your token stays private. Set your API key & secret as env vars on Render, then log in below.
